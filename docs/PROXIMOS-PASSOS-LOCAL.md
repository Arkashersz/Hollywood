# Preparação no computador principal

O passo a passo atual está no `README.md` da raiz (seções "Preparação" e "Uso diário").

## Segurança
- Não compartilhe a chave `sb_secret_…`, senhas ou cookies.
- Não copie o perfil do Chrome do worker (`worker/browser-profiles/`) para a nuvem.
- O worker só faz conexões de saída para o Supabase; não abra porta pública no roteador.
- Se a rede corporativa bloquear o painel, peça liberação ao TI; não contorne os controles.
